# 📂 Featured Project — DocVault

### 🤖 AI-Powered Document Management & Retrieval Platform

**DocVault** is an AI-powered document management platform designed to securely organize, retrieve, search, and automate document workflows.

The project combines a traditional full-stack architecture with **RAG, vector search, LLMs, agentic workflows, background processing, and AI evaluation**.

### ✨ Key Features

* 🔐 **Authentication & Authorization**

  * JWT authentication
  * HTTP-only cookies
  * Refresh-token rotation
  * Role-Based Access Control (**RBAC**)

* 📁 **Document Management**

  * Smart folder organization
  * Secure document storage
  * Document sharing
  * Access control
  * Document expiry detection

* 🔎 **AI-Powered Retrieval**

  * **RAG (Retrieval-Augmented Generation)**
  * Semantic / vector search
  * **pgvector**
  * Embeddings
  * Context-aware document retrieval
  * Source citations

* 🤖 **AI Document Assistant**

  * Google **Gemini**
  * **LangChain**
  * **LangGraph**
  * Conversational document querying
  * AI summarization
  * Agentic workflows

* 🌐 **External Web Search**

  * **Tavily**
  * **Tavily MCP**
  * MCP-based tool integration
  * Combining internal document knowledge with external web information

* 🧪 **AI Evaluation & Observability**

  * **LLM-as-a-Judge**
  * RAG evaluation
  * Retrieval quality analysis
  * **LangSmith**
  * LLM tracing and observability

* ⚙️ **Asynchronous Processing**

  * **BullMQ**
  * **Redis**
  * Background workers
  * Queue-based document processing

* 📄 **Document Processing**

  * OCR
  * **Tesseract.js**
  * Text extraction
  * Document preprocessing

* 🐳 **Infrastructure & Deployment**

  * Docker
  * Docker Compose
  * Nginx
  * Containerized services
  * Horizontal-scaling architecture
  * Render deployment
  * Supabase infrastructure
